# Contributing to Myelinated Memory

First off, thank you for considering contributing to Myelinated Memory!

## How can I contribute?

- **Reporting Bugs:** Create an issue describing the bug.
- **Suggesting Enhancements:** Open an issue to discuss new features or biomimetic logic.
- **Code Contributions:**
    1. Fork the repo.
    2. Create a feature branch (`git checkout -b feature/amazing-feature`).
    3. Commit changes (`git commit -m 'Add amazing feature'`).
    4. Push to branch (`git push origin feature/amazing-feature`).
    5. Open a Pull Request.

## Coding Standards
- Maintain Python 3.11 compatibility.
- Ensure all logic remains zero-dependency (stdlib only).
